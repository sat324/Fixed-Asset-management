# Fixed Asset Management System

## 📌 Project Overview

The **Fixed Asset Management System** is a Java-based application designed to manage and maintain information about an organization's fixed assets.

It helps users store, update, search, and manage asset-related information in an organized way.

## 🎯 Objectives

* Manage fixed asset records
* Add new assets
* Update existing asset information
* Search and view asset details
* Maintain asset records efficiently
* Reduce manual record management

## 🛠️ Technologies Used

* **Java**
* **JDBC**
* **MySQL**
* **Object-Oriented Programming (OOP)**

## ✨ Main Features

* Add Asset
* View Asset Details
* Search Asset
* Update Asset
* Delete Asset
* Manage Asset Records
* Database Connectivity using JDBC

## ⚙️ How to Run

1. Install Java JDK.
2. Install MySQL.
3. Create the required database in MySQL.
4. Configure the database username and password in the Java project.
5. Add the MySQL JDBC Driver.
6. Compile and run the main Java file.

## 💾 Database

The project uses **MySQL** to store fixed asset information.

JDBC is used to establish the connection between the Java application and MySQL database.
